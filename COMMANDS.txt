ThemisForge - commands (run from the project root)

Development (hot reload)
  ./themis start     rebuild the frontend, then start backend (8000) + frontend (5173) with hot reload
  ./themis build     only rebuild the frontend (what http://localhost:8000 serves)
  ./themis build-images  build the cell image for Codex agents (once, and after Dockerfile changes)
  ./themis stop      stop both
  ./themis status    show what is running
  ./themis logs      follow both logs (Ctrl+C to leave)

  Then open http://localhost:5173 (live reload) or http://localhost:8000 (the fresh build)

  First time only, if ./themis start fails: it installs dependencies itself, so just make sure
  uv and npm are installed.

Install on a computer or server (Linux; no need to clone this repository)
  curl -fsSL https://github.com/RT-codes/ThemisForge/releases/latest/download/install.sh | sh
                                 installs the newest release into ~/.local/share/themis, checks Docker, writes the
                                 settings with a new secret key, registers a service and starts it
  Then, wherever you are:
  themis status                  what is installed and whether it is running
  themis upgrade                 upgrade to the newest version (backup first, rolls back if it fails); --check looks only
  themis doctor [--report]       check Python, Docker, the database; show how the last starts went
  themis restart | stop | start | logs
  themis backup                  save a copy of the database and settings
  themis uninstall               remove it (your data stays unless --purge)
  (`./themis` in this repository is only for development.)

Checks
  cd backend && uv run pytest && uv run ruff check .
  cd frontend && npm run check

Database changes
  cd backend && uv run alembic revision --autogenerate -m "what changed"   (then review the file)
  Migrations run automatically when the server starts.

Production-style (one server, serves the built frontend on http://localhost:8000)
  cd frontend && npm run build
  cd backend && uv run uvicorn app.main:app
