ThemisForge - commands (run from the project root)

  ./themis start     start backend (8000) + frontend (5173) with hot reload
  ./themis stop      stop both
  ./themis status    show what is running
  ./themis logs      follow both logs (Ctrl+C to leave)

Then open http://localhost:5173

First time only, if ./themis start fails: it installs dependencies itself, so just make sure
uv and npm are installed.

Checks:
  cd backend && uv run pytest && uv run ruff check .
  cd frontend && npm run check

Production-style (one server, serves the built frontend on http://localhost:8000):
  cd frontend && npm run build
  cd backend && uv run uvicorn app.main:app
